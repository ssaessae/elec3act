Drop your own product photos in this folder.

1. Name each file after the product's `slug` in src/data/products.ts
   (for example: lucky-me-pancit-canton.jpg).
2. In src/data/products.ts set  USE_PLACEHOLDER_IMAGES = false.

Any file that is missing falls back to a neutral placeholder automatically,
so you can replace images one at a time. If your files use another extension
(.webp, .png), change IMAGE_EXTENSION in src/data/products.ts.
